# Исходники статей блога

Каждая статья — один файл `<адрес>.md`. Страницу `blog/<адрес>/index.html`,
карточку в `blog/index.html` и строку в `sitemap.xml` собирает скрипт:

```bash
pult/.venv/bin/python tools/article.py            # все статьи
pult/.venv/bin/python tools/article.py menyu-dlya-kofejni   # одну
```

## Публикация по расписанию

Статьи пишутся заранее, партией. У каждой — время выхода по Москве:
`published: 2026-10-25 09:00`. Пока оно не наступило, генератор статью не
собирает: её нет ни на сайте, ни в списке, ни в sitemap. Посмотреть такую
статью локально можно предпросмотром — список и sitemap он не трогает:

```bash
pult/.venv/bin/python tools/article.py --preview franshiza-kofejni
```

Готовую партию коммитим и выкатываем как обычно — `tools/publish.sh` на
сервере (см. README в корне). Дальше cron в 9:05 и 15:05 сам пересобирает
блог: у статей, чьё время пришло, появляются страница, карточка и строка в
sitemap, и сразу уходит уведомление в IndexNow. Ритм — две статьи в день,
слоты 09:00 и 15:00.

Отправить адреса в IndexNow руками (если ругается на сертификат — тем же
`pult/.venv/bin/python`):

```bash
python3 tools/indexnow.py /blog/menyu-dlya-kofejni/
```

Поля совпадают с моделью `Article` в `pult/content/models.py`, чтобы статьи
можно было перенести в пульт без переписывания.

## Формат файла

```
---
slug: menyu-dlya-kofejni
title: Меню для кофейни: что включить и как посчитать цены
description: До 160 знаков: сниппет в выдаче.
h1: Меню для кофейни:<br>состав, объёмы и цены
crumb: Меню для кофейни
meta: Меню · Деньги
card: Две-три фразы для карточки в списке статей.
published: 2026-10-22
lede: Абзац под заголовком, крупным шрифтом.
faq_title: Что спрашивают про меню кофейни
call_title: Заголовок призыва в конце
call_text: Текст призыва — одно-два предложения.
---
Первый абзац статьи (без заголовка).

## Подзаголовок

Обычный Markdown: **жирный**, списки, таблицы, [ссылка](/sklad/).

> [Формула]
> Фудкост, % = себестоимость ÷ цена × 100

=== faq

### Вопрос, как его задают в поиске?
Ответ. Абзацы — через пустую строку.

### Второй вопрос?
Ответ.

=== related

- /blog/fudkost/ | Фудкост | Подпись под ссылкой
- /qr-menu/ | QR-меню | Подпись
```

Правила:

- `title` — до 60 знаков, с главным запросом в начале. `description` — до 160.
- `h1` не повторяет `title` дословно; перенос строки — `<br>`.
- Цитата `>` становится оранжевой врезкой. Первая строка в квадратных
  скобках — метка врезки (`[Формула]`, `[Пример]`, `[Падача считает это сама]`).
- Колонки таблицы, где только числа, выравниваются вправо сами.
- Заголовки `#` в тексте превращаются в `##`: h1 на странице один.
- В `=== faq` — вопросы для блока и для FAQPage в микроразметке.
- В `=== related` — три ссылки «Рядом по теме»: адрес | название | подпись.
