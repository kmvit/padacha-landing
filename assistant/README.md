# ИИ-ассистент «Падачи»

Отвечает на вопросы о работе сервиса в чате на padacha.ru.

## Откуда берётся знание

```
data/product/*.json   ← как работает продукт. Правится руками, вычитывается глазами
index.html (сайта)    ← тарифы, цены и частые вопросы. ЕДИНСТВЕННЫЙ источник цен
        │
        ▼  python -m scripts.export_kb
data/kb.json          ← снапшот целиком, его читает сервис (не в git — генерируется)
```

Цены в файлах ассистента не дублируются намеренно. Две копии неизбежно
разъедутся, и ассистент назовёт клиенту цену, которой на сайте нет —
опровергнуть её будет нечем. Поправили цену в `index.html` → пересобрали
снапшот → ассистент знает новую.

## Файлы знания

| Файл | О чём |
|---|---|
| `00-общее.json` | что за продукт, форматы работы, запуск, оборудование |
| `10-гость.json` | меню по QR, виды меню, как гость заказывает |
| `20-официант.json` | карта столов, заявки, счета, оплата |
| `30-кухня-бар.json` | канбан станций, тайминги, стоп-лист |
| `40-стойка.json` | формат без зала: номера и выдача |
| `50-склад.json` | остатки, тех. карты, приход по фото, себестоимость |
| `60-смены.json` | учёт дней, ставка и бонус |
| `70-финансы.json` | ведомость, расходы, отчёт о прибыли, права доступа |
| `80-настройка.json` | бренд, оформление, меню, несколько точек |
| `policy.json` | тон, границы, что делать при незнании |

У каждой темы есть поле **`чего_нет`** — это не забытая часть, а рабочий
инструмент. Ассистент, который умеет прямо сказать «этого в системе нет»,
полезнее уклончивого: клиент не купит подписку под несуществующую функцию
и не вернётся с претензией.

## Почему всё знание идёт в промпт целиком

Собранный снапшот — около 14 500 знаков (≈4 800 токенов). Это мало, и он
помещается в системный промпт полностью.

Разбор по темам с дозагрузкой по запросу выглядит экономнее, но ломается там,
где вопросы межтемные: «а официант увидит себестоимость?» — это роли, финансы
и права доступа сразу. Если модель не дозапросила нужный кусок, она отвечает
из воздуха — ровно та беда, от которой мы защищаемся, и провал молчаливый.

Файлы всё равно разделены: так их правят и вычитывают. Когда снапшот перевалит
тысяч за сорок знаков или появится знание про конкретные заведения, переезд
будет дешёвым — оглавление тем в промпте плюс инструмент `get_topic`. Менять
придётся только сборку, содержимое останется.

## Как обновлять

```bash
python -m scripts.export_kb
```

Запускается перед каждым стартом сервиса, так что перезапуск всегда означает
свежие данные.
