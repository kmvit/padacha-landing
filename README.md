# Падача — лэндинг

Одностраничный сайт продукта «Падача» — системы управления кафе.
Весь сайт это один самодостаточный `index.html`: без сборки, без
зависимостей, только Google Fonts снаружи.

## Посмотреть локально

```bash
python3 -m http.server 8123
```

Открыть http://localhost:8123

## Что внутри

- Тёмная и светлая темы, переключатель в шапке запоминает выбор
  (`localStorage`, ключ `padacha-theme`). По умолчанию тёмная.
- Тарифы: переключатель «помесячно / за год» пересчитывает цены из
  `data-month` и `data-year` прямо в разметке — править цены там.
- Сравнение с конкурентами — ширины полос в `style="--w: …"`, проценты
  считались от самой дорогой строки.
- Живая лента чеков в первом экране — на `setInterval`, отключается при
  `prefers-reduced-motion`.

## Домен и деплой

Домен: **padacha.ru**. Сайт лежит на том же сервере, что и ganin-site
(`a318f7177847.vps.myjino.ru`, nginx на хосте), в `/opt/padacha`.
Раскатка — `git pull` в этой папке, сборки нет.

## Правки

Цены, тарифы и тексты лежат прямо в разметке — искать по названию
тарифа. Цифры конкурентов проверялись в августе 2026 на сайтах
iiko.ru, quickresto.ru и rkeeper.ru, их стоит перепроверять.
