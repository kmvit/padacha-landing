# Падача — лэндинг

Одностраничный сайт продукта «Падача» — системы управления кафе.
Весь сайт это один самодостаточный `index.html`: без сборки, без
зависимостей, только Google Fonts снаружи.

## Посмотреть локально

```bash
python3 -m http.server 8123
```

Открыть http://localhost:8123

## Что внутри

- Тёмная и светлая темы, переключатель в шапке запоминает выбор
  (`localStorage`, ключ `padacha-theme`). По умолчанию тёмная.
- Тарифы: переключатель «помесячно / за год» пересчитывает цены из
  `data-month` и `data-year` прямо в разметке — править цены там.
- Сравнение с конкурентами — ширины полос в `style="--w: …"`, проценты
  считались от самой дорогой строки.
- Живая лента чеков в первом экране — на `setInterval`, отключается при
  `prefers-reduced-motion`.

## Оформление: две темы

У сайта два оформления, и переключаются они одной командой:

```bash
python3 tools/theme.py              # какая тема стоит сейчас
python3 tools/theme.py --set riso
python3 tools/theme.py --set classic
```

- **classic** — тёмное оформление, с которым сайт жил до октября 2026.
- **riso** — двухкрасочная печать по бежевой бумаге: `theme-riso.css`.

Сборки по-прежнему нет. Внутренние страницы переключаются одной строкой
`<link>` в `<head>`: `theme-riso.css` подключается поверх `page.css` и
`nav.css` и переопределяет токены, шрифты и печатные детали. Разметку
страниц тема не трогает вовсе — отсюда и обратимость.

Главную строкой стилей не переключить, у неё своя вёрстка под каждое
оформление, поэтому скрипт подменяет сам файл:

```
riso/index.html     ← исходник ризо-главной, правится здесь
home-classic.html   ← прежняя главная
index.html          ← копия активной, её отдаёт nginx
```

Пути в `riso/index.html` относительные, чтобы черновик открывался двойным
кликом без сервера; при установке в корень скрипт выпрямляет их сам.
Шапку и подвал обеим версиям по-прежнему раскладывает `tools/header.py`.

Иллюстрации в шапке ризо-главной (`riso/img/tile-*.webp`) взяты из галереи
Kombai — они сгенерированы для вымышленной закусочной. Для своих блюд
исходники лежат в `shots/`.

## Домен и деплой

Домен: **padacha.ru**. Сайт лежит на том же сервере, что и ganin-site
(`a318f7177847.vps.myjino.ru`, порт ssh 49197), в `/opt/padacha`.
Отдаётся статикой напрямую nginx хоста — конфиг
`/etc/nginx/sites-available/padacha`. Сосед (ganin) работает через
127.0.0.1:8001 и никак не задет.

Обновить сайт — не голым `git pull`, а скриптом: он ещё и пересобирает
блог по времени публикации статей и сообщает о новых поисковикам (IndexNow):

```bash
ssh -J vpn -p 49197 root@a318f7177847.vps.myjino.ru /opt/padacha/tools/publish.sh
```

Тот же скрипт стоит в cron на 9:05 и 15:05 по Москве — так выходят статьи,
написанные заранее (`published: 2026-10-25 09:00` в content/blog/*.md).
Лог — `/var/log/padacha-publish.log`. Для сборки на сервере отдельное окружение
`/opt/padacha-build` (python + markdown).
Перезапускать nginx не нужно — html не кэшируется.

### Что осталось до запуска

1. Направить домен на сервер: A-запись `padacha.ru` и `www.padacha.ru`
   → **217.107.34.211**.
2. Когда домен начнёт резолвиться — выпустить сертификат:

```bash
certbot --nginx -d padacha.ru -d www.padacha.ru
```

Certbot 2.9 с плагином nginx на сервере уже стоит, автопродление
работает (по нему живёт сертификат ganin).

## Правки

Цены, тарифы и тексты лежат прямо в разметке — искать по названию
тарифа. Цифры конкурентов проверялись в августе 2026 на сайтах
iiko.ru, quickresto.ru и rkeeper.ru, их стоит перепроверять.
